## 1. 唯一一行代码改动

test_verify_reviewer.py 第 419-428 行（改动落在第 422 行）：

```python
    j = os.path.join(base, "delivery_junc")
    try:
        make_junction(DATA, j)
    except (OSError, subprocess.CalledProcessError) as e:
        reason = ("当前环境无法创建 junction（需 NTFS 且沙箱与数据同卷；"
                  "跨卷、FAT/exFAT、非管理员受限场景均会失败）")
```

目的：只把「环境不具备 junction 创建条件」这类预期失败降级为 SKIP；
OSError 覆盖文件系统/权限失败，subprocess.CalledProcessError 覆盖 mklink
子进程失败。非预期的接口错误（例如 TypeError）不再被吞掉。

代码事实：本轮只收窄 T7 这一处。该文件仍有 6 处 `except Exception as e:`，
位于第 258 行（t3）、第 290 行（t4）、第 399 行（t6）、第 498 行（t8）、

```python
    expected = Counter(EXPECTED_CID_COUNTS)
    missing = sorted(set(expected) - set(counter))
    extra = sorted(set(counter) - set(expected))
    drift = {k: (counter.get(k), expected.get(k))
             for k in set(expected) | set(counter)
             if counter.get(k) != expected.get(k)}
    check("S4 唯一 cid 数固定为 46", len(counter) == 46,
          "unique=%d baseline=%d" % (len(counter), len(expected)))
    check("S4 46 个 cid 分布与固定基线逐项一致",
          counter == expected,
          "缺失=%r 多出=%r 计数差异=%r" % (missing, extra, drift))
```

口径：81 是断言记录数，46 是唯一 cid 数；cid 是分组标签，不是唯一断言
编号。复用 ID 只有 T1（28 次）、T3（5 次）、T5g（5 次），其余 43 个各 1，
合计 81。任一测试组增删或 cid 改名都会让 S4 断言失败。

### 2.2 S5 TypeError 注入（第 290-342 行）

`tv.make_junction = raise_typeerror` 后，TypeError 不被收窄后的 except 捕获：

- SKIPPED 为空，RESULTS 为空，未打印 [SKIP] T7a；
- 单元级 t7() 抛出异常；
- 进程级完整 main() 以非零退出码终止，未走到汇总统计行。

如实说明：实际表现是「未捕获异常向上抛出、进程退出码非 0」，不是以

## 6. 统计口径（与 r3 回信 4.1 节一致）

test_verify_reviewer.py 第 100-115 行、第 724-739 行：

```python
def check(cid, desc, cond, detail=""):
    RESULTS.append((cid, desc, bool(cond), detail))
    print("  [%s] %-4s %s" % ("PASS" if cond else "FAIL", cid, desc))
    if detail:
        for line in str(detail).splitlines():
            print("            %s" % line)


def skip(cid, desc, reason=""):
    """记录"环境不具备测试条件"。与 FAIL 区分：不计入 PASS，也不影响退出码。"""
    SKIPPED.append(cid)
    RESULTS.append((cid, desc, True, reason))
    print("  [SKIP] %-4s %s" % (cid, desc))
    if reason:
        for line in str(reason).splitlines():
            print("            %s" % line)
```

```python
    n = len(RESULTS)
    bad = [r for r in RESULTS if not r[2]]
    n_skip = len(SKIPPED)
    n_pass = n - n_skip - len(bad)
    print("\n" + "=" * 78)
    print("统计：共 %d 项，PASS=%d SKIP=%d FAIL=%d"
          % (n, n_pass, n_skip, len(bad)))
    if SKIPPED:
        print("  SKIP 明细（环境不具备条件，不代表被测代码有问题，也不计 PASS）：%s"
              % ", ".join(SKIPPED))
    if bad:
        for cid, desc, _, detail in bad:
            print("  FAIL [%s] %s" % (cid, desc))
    print("结论：%s" % ("ALL PASS（无 FAIL）" if not bad else "存在失败"))
    print("=" * 78)
    return 0 if not bad else 1
```

skip() 同时写 SKIPPED 和 RESULTS，SKIPPED 是 RESULTS 的 cid 子集，因此
`N = len(RESULTS)`；`|RESULTS| + |SKIPPED|` 会重复计数。受限环境实测
len(RESULTS)=74、len(SKIPPED)=5、两者相加为 79，故汇总只取
`n = len(RESULTS)`。退出码严格由 bad（FAIL）决定，SKIP 不触发非零。
